# ATM Java Project

This is a simple console-based ATM simulation written in Java. Users can log in with a customer number and PIN, then manage Checking and Savings accounts to view balances, deposit, and withdraw funds.

## Features

- User authentication with customer number and PIN  
- Support for Checking and Savings accounts  
- View balance, deposit, and withdraw funds with validation  
- Console-based menu system for easy navigation  
- Object-oriented design principles  

## Project Structure

- `src/` — Contains Java source code files  
- IDE configuration files (optional) may be present but are not required to run the project  

## How to Run

1. Clone or download the repository.  
2. Open the project folder in any Java IDE (Eclipse, IntelliJ IDEA, VS Code) or compile and run from the command line.  
3. Run the `Atm` class to start the program.  
4. Follow the console prompts to interact with the ATM simulation.

## Notes

- Login credentials and account data are hardcoded for demonstration purposes.  
- The program prevents negative balances through input validation.  
- Suitable for learning Java basics, OOP, and console application design.
